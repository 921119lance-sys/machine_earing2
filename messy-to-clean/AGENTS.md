# Project instructions

## Folder map

- `README.md`: Project home page, student details, and progress log.
- `AGENTS.md`: Project working rules.
- `.gitignore`: Files to keep out of GitHub.
- `data/raw/`: Original datasets.
- `data/interim/`: Temporary data from cleaning.
- `data/processed/`: Final cleaned datasets.
- `notebooks/`: Exploration and analysis notebooks.
- `src/`: Reusable code.
- `reports/`: Report drafts, final PDF, and slides.
- `reports/figures/`: PNG charts.
- `references/`: Brief, papers, codebook, and lecturer feedback.

## Rules

1. Never change anything in `data/raw/`.
2. Save cleaned data in `data/processed/`.
3. Reusable code goes in `src/`.
4. Charts go in `reports/figures/` as PNG.
5. Never put data files on GitHub.
6. After every work session, add a row to the Progress log in `README.md`.
7. Always give the exact path and a code block for every file.
8. Explain everything in simple English.
9. Ask before deleting anything.
